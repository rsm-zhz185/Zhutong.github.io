1.Introduction

In this project, we explore two fundamental branches of machine learning—unsupervised and supervised learning—by implementing multiple algorithms from scratch. Our goal is to understand not only how these methods work, but also when and why they are effective tools for marketing analytics.

We begin with K-Means Clustering, an unsupervised learning algorithm that helps uncover hidden segments in data. Using the well-known penguins dataset, we identify natural groupings based on physical measurements such as bill length and flipper size. This mirrors real-world business applications like customer segmentation.

Next, we examine two complementary supervised learning methods:

  • Key Drivers Analysis: We apply a range of regression-based techniques—including Pearson R², standardized coefficients, usefulness (ΔR²), SHAP values, and tree-based variable importance—to determine which customer perceptions most influence satisfaction. This analysis reflects real-world business needs to explain and prioritize actionable factors.

  • K-Nearest Neighbors (KNN): We also implement KNN for classification on a yogurt purchase dataset. By visualizing how the model behaves under different values of K (e.g., K=1 and K=15), we explore model flexibility and the bias-variance tradeoff, as illustrated in Slide 19 from class.

By combining clustering, interpretation, and classification techniques, we reinforce our understanding of distance-based learning methods, explore their assumptions, and assess their performance across a variety of practical contexts.

K-Means Clustering: Algorithm by Hand

import pandas as pd
import numpy as np
import matplotlib.pyplot as plt
from sklearn.preprocessing import StandardScaler
import seaborn as sns


# Select features for K-Means clustering
features = ['bill_length_mm', 'bill_depth_mm', 'flipper_length_mm', 'body_mass_g']
penguins_features = penguins_df[features].dropna()

# Standardize the features
scaler = StandardScaler()
X = scaler.fit_transform(penguins_features)

# Implement K-Means manually
def initialize_centroids(X, k):
    np.random.seed(42)
    random_indices = np.random.permutation(X.shape[0])[:k]
    return X[random_indices]

def assign_clusters(X, centroids):
    distances = np.linalg.norm(X[:, np.newaxis] - centroids, axis=2)
    return np.argmin(distances, axis=1)

def update_centroids(X, labels, k):
    return np.array([X[labels == i].mean(axis=0) for i in range(k)])

# Run the algorithm
def kmeans(X, k=3, max_iters=100, tol=1e-4):
    centroids = initialize_centroids(X, k)
    for i in range(max_iters):
        labels = assign_clusters(X, centroids)
        new_centroids = update_centroids(X, labels, k)
        if np.allclose(centroids, new_centroids, atol=tol):
            break
        centroids = new_centroids
    return labels, centroids

# Apply K-Means
labels, final_centroids = kmeans(X, k=3)

# Add cluster labels to original DataFrame
penguins_clustered = penguins_features.copy()
penguins_clustered['cluster'] = labels

K-Means clustering partitions observations into ( K ) clusters such that each observation belongs to the cluster with the nearest mean. Here’s how the algorithm works:

  1. Initialization: Randomly assign ( K ) initial cluster centers (centroids).
  2. Assignment Step: For each data point, compute the distance to each centroid and assign the point to the nearest one.
  3. Update Step: Recalculate each centroid as the mean of all points assigned to its cluster.
  4. Repeat: Iterate the assignment and update steps until the cluster assignments no longer change or the maximum number of iterations is reached.

We implement this algorithm from scratch, using only basic Python operations, without relying on sklearn.cluster.KMeans. This allows us to observe the inner workings of the algorithm—especially how centroids shift and clusters stabilize over time.

Variable Importance Methods

We compare six variable importance techniques to determine which features most influence satisfaction:

  • Pearson R²: Measures how strongly each variable is correlated with the response.
  • Standardized Coefficients: From a linear regression with standardized inputs.
  • Usefulness (ΔR²): The drop in R² from removing a variable from the model.
  • SHAP (Linear): Shapley values approximated for a linear model.
  • Johnson’s Relative Weights: A fast, algebraic approximation of Shapley values for regression.
  • Random Forest Gini Importance: Based on how much each feature reduces impurity across decision trees.

Key Drivers Table

The table below shows the percentage importance of each variable under the six methods. The values are normalized so that each column sums to 100%.

from sklearn.linear_model import LinearRegression
from sklearn.ensemble import RandomForestRegressor
from sklearn.inspection import permutation_importance
from sklearn.metrics import r2_score
from sklearn.preprocessing import StandardScaler
from sklearn.base import clone
import shap

# Prepare data for supervised learning
drivers_clean = drivers_df.dropna()
X = drivers_clean.drop(columns=['brand', 'id', 'satisfaction'])
y = drivers_clean['satisfaction']

# Standardize features for linear methods
scaler = StandardScaler()
X_scaled = scaler.fit_transform(X)
X_df = pd.DataFrame(X_scaled, columns=X.columns)

# 1. Pearson Correlations (R^2)
pearson_r2 = X_df.corrwith(y).pow(2)

# 2. Standardized Coefficients
reg = LinearRegression().fit(X_scaled, y)
std_coefs = pd.Series(reg.coef_ * X_df.std(), index=X.columns)

# 3. Usefulness: ΔR^2 from dropping each variable
full_r2 = r2_score(y, reg.predict(X_scaled))
usefulness = {}
for col in X.columns:
    cols_minus = [c for c in X.columns if c != col]
    X_minus = X_df[cols_minus]
    r2_minus = r2_score(y, LinearRegression().fit(X_minus, y).predict(X_minus))
    usefulness[col] = full_r2 - r2_minus
usefulness = pd.Series(usefulness)

# 4. SHAP Values for Linear Regression
explainer = shap.Explainer(reg, X_df)
shap_values = explainer(X_df)
shap_importance = pd.DataFrame(shap_values.values, columns=X.columns).abs().mean()

# 5. Johnson's Epsilon (approx. via squared beta * variance of X)
johnson = pd.Series(reg.coef_**2 * X_df.var().values, index=X.columns)

# 6. Random Forest Gini Importance
rf = RandomForestRegressor(random_state=42).fit(X, y)
rf_importance = pd.Series(rf.feature_importances_, index=X.columns)

# Combine all into one DataFrame
importance_df = pd.DataFrame({
    'Pearson R2': pearson_r2,
    'Std Coef': std_coefs.abs(),
    'Usefulness': usefulness,
    'SHAP (Linear)': shap_importance,
    'Johnson Epsilon': johnson,
    'RF Gini': rf_importance
})

# Normalize to 100% within each column
importance_percent = importance_df.divide(importance_df.sum()) * 100
importance_percent = importance_percent.round(1)

pd.set_option('display.max_rows', None)
display(importance_percent)

KNN: Visualizing Model Flexibility

To explore how the choice of model affects classification behavior, we implemented and visualized three models trained on yogurt brand choice data:

  • A linear classifier (Logistic Regression)
  • K-Nearest Neighbors with K = 15
  • K-Nearest Neighbors with K = 1

The figure below replicates the visual style of Slide 19 from class, showing how each model divides the input space (p1 vs. p2) into regions corresponding to brand predictions.

import numpy as np
import matplotlib.pyplot as plt
from sklearn.neighbors import KNeighborsClassifier
from sklearn.linear_model import LogisticRegression
from sklearn.model_selection import train_test_split
from matplotlib.colors import ListedColormap

# Load yogurt dataset again and prepare
yogurt_data = yogurt_df.copy()
X = yogurt_data[['p1', 'p2']]  # use two features for 2D visualization
y = yogurt_data[['y1', 'y2', 'y3', 'y4']].idxmax(axis=1)  # assign class based on one-hot max

# Encode 'y1' -> 0, 'y2' -> 1, etc.
y = y.str.extract('(\d)').astype(int) - 1
y = y[0]

# Train/test split
X_train, X_test, y_train, y_test = train_test_split(X, y, stratify=y, random_state=42)

# Train models
logreg = LogisticRegression().fit(X_train, y_train)
knn_15 = KNeighborsClassifier(n_neighbors=15).fit(X_train, y_train)
knn_1 = KNeighborsClassifier(n_neighbors=1).fit(X_train, y_train)

# Meshgrid for plotting decision boundaries
h = 0.01
x_min, x_max = X_train.iloc[:, 0].min() - 0.05, X_train.iloc[:, 0].max() + 0.05
y_min, y_max = X_train.iloc[:, 1].min() - 0.05, X_train.iloc[:, 1].max() + 0.05
xx, yy = np.meshgrid(np.arange(x_min, x_max, h),
                     np.arange(y_min, y_max, h))
grid = np.c_[xx.ravel(), yy.ravel()]

# Predict for each model
Z_logreg = logreg.predict(grid).reshape(xx.shape)
Z_knn15 = knn_15.predict(grid).reshape(xx.shape)
Z_knn1 = knn_1.predict(grid).reshape(xx.shape)

# Plotting
fig, axes = plt.subplots(1, 3, figsize=(18, 5))
cm = ListedColormap(['#FFA07A', '#87CEFA', '#90EE90', '#DDA0DD'])

titles = ['Linear Regression', 'K=15', 'K=1']
models = [(Z_logreg, logreg), (Z_knn15, knn_15), (Z_knn1, knn_1)]
